## 1. InputControlUtils：触摸注入（核心）

引擎进程以 shell 身份向目标 display 注入 MotionEvent/KeyEvent：

```java
public final class InputControlUtils {
    private static final int DEFAULT_DEVICE_ID = 0;
    private static final int DEFAULT_SOURCE = InputDevice.SOURCE_TOUCHSCREEN;

    // 单指针事件复用静态数组（避免每帧 new）
    private static final MotionEvent.PointerProperties[] POINTER_PROPERTIES = new PointerProperties[1];
    private static final MotionEvent.PointerCoords[] POINTER_COORDS = new PointerCoords[1];
    static {
        props.id = 0; props.toolType = TOOL_TYPE_FINGER;
    }

    private static long currentDownTime = 0;   // 当前触摸序列的 down 时间戳
```

### 事件构造

```java
private static MotionEvent obtainTouchEvent(downTime, eventTime, action, x, y, pressure) {
    coords.x = max(0, x); coords.y = max(0, y); coords.pressure = pressure; coords.size = 1.0f;
    return MotionEvent.obtain(downTime, eventTime, action, 1, POINTER_PROPERTIES, POINTER_COORDS,
        0, 0, 1.0f, 1.0f, DEFAULT_DEVICE_ID, 0, DEFAULT_SOURCE, 0);
}

private static boolean injectInputEvent(MotionEvent event, int displayId, int mode) {
    if (!setDisplayId(event, displayId)) return false;   // 指定目标屏
    notifyTouchCallback(event);                          // 触摸回调（预览/手势分析）
    try { return getManager().injectInputEvent(event, mode); }
    finally { event.recycle(); }
}
```

### down/move/up 三件套（含状态保护）

```java
public static synchronized boolean down(int x, int y, int displayId) {
    // ★ 若上次序列未正常结束（currentDownTime != 0），先补发 ACTION_CANCEL 清空触控槽位
    if (currentDownTime != 0) {
        injectInputEvent(obtainTouchEvent(currentDownTime, now, ACTION_CANCEL, x, y, 0), displayId, ASYNC);
    }
    currentDownTime = SystemClock.uptimeMillis();
    // ★ DOWN 用 WAIT_FOR_FINISH：确保起始状态被系统真正接收（防丢首帧）
    return injectInputEvent(obtainTouchEvent(now, now, ACTION_DOWN, x, y, 1.0f), displayId, WAIT_FOR_FINISH);
}

public static synchronized boolean move(int x, int y, int displayId) {
    if (currentDownTime == 0) return false;
    return injectInputEvent(obtainTouchEvent(currentDownTime, now, ACTION_MOVE, x, y, 1.0f), displayId, ASYNC);
}

public static synchronized boolean up(int x, int y, int displayId) {
    if (currentDownTime == 0) return false;
    boolean result = injectInputEvent(obtainTouchEvent(currentDownTime, now, ACTION_UP, x, y, 0), displayId, ASYNC);
    currentDownTime = 0;   // 复位
    return result;
}
```

**细节设计**：
- `synchronized`：注入线程安全（MaaCore 与预览触摸可能并发）。
- **DOWN 之前补 ACTION_CANCEL**：防止上次 UP 丢失导致触控槽位被占用（滑动卡死的防护）。
- **DOWN 用 WAIT_FOR_FINISH、MOVE/UP 用 ASYNC**：DOWN 必须确认被系统处理，高频 MOVE 异步不阻塞。
- `setDisplayId(event, displayId)`：虚拟屏注入的关键——事件要打到虚拟屏 display。

### 触摸回调转发（预览/手势分析）

```java
public static void setTouchCallback(ITouchEventCallback callback) { touchCallback = callback; }

private static void notifyTouchCallback(MotionEvent event) {
    ITouchEventCallback cb = touchCallback;
    if (cb == null) return;
    try {
        cb.onCallback(Math.round(event.getX()), Math.round(event.getY()), event.getActionMasked());
    } catch (RemoteException | RuntimeException e) {
        touchCallback = null;   // 回调失败 → 注销，避免反复抛
        Ln.w("touch callback failed, clearing registration", e);
    }
}
```
App 侧通过 `setTouchCallback` 接收引擎内注入的触摸事件（用于触摸预览/手势分析），失败自动注销防刷屏。

## 2. PowerController：屏幕电源控制

### 物理屏熄/亮（SurfaceControl）

```kotlin
fun setDisplayPower(on: Boolean): Boolean {
    flag = !on                                    // /data/local/tmp/maa_power_off_flag 落盘标记
    return setDisplayPowerInternal(on)
}

private fun setDisplayPowerInternal(on: Boolean): Boolean {
    // 荣耀 Android14+ 特判：不要遍历多物理屏（防止误关）
    var applyToMultiPhysicalDisplays = SDK >= 29
    if (SDK >= 34 && BRAND == "honor" && SurfaceControl.hasGetBuildInDisplayMethod()) {
        applyToMultiPhysicalDisplays = false
    }
    val mode = if (on) POWER_MODE_NORMAL else POWER_MODE_OFF

    if (applyToMultiPhysicalDisplays) {
        // Android10+ 遍历所有物理屏（折叠屏/双屏都熄）
        val ids = if (SDK >= 34 && !SurfaceControl.hasGetPhysicalDisplayIdsMethod())
            DisplayControl.getPhysicalDisplayIds() else SurfaceControl.getPhysicalDisplayIds()
        for (id in ids) {
            val binder = ...getPhysicalDisplayToken(id)
            allOk = allOk and SurfaceControl.setDisplayPowerMode(binder, mode)
        }
        return allOk
    }
    // 单屏：SurfaceControl.setDisplayPowerMode(getBuiltInDisplay(), mode)
}
```

**细节**：
- **flag 落盘**（`/data/local/tmp/maa_power_off_flag`）：进程异常退出后，下次启动读 flag 决定是否恢复屏幕（紧急恢复的依据）。
- **荣耀特判**：Android14+ 荣耀遍历多物理屏可能误关内置屏，特殊绕过。
- `SurfaceControl` 是系统隐藏类，反射 `getBuiltInDisplay/getPhysicalDisplayIds/getPhysicalDisplayToken/setDisplayPowerMode`。

### 虚拟屏保亮（userActivity keep-alive）

```kotlin
fun startUserActivityKeepAlive(displayId: Int) {
    keepAliveDisplayId.set(displayId)
    if (!keepAliveRunning.compareAndSet(false, true)) return   // 防重入
    Thread {
        while (true) {
            val id = keepAliveDisplayId.get()
            if (id == DISPLAY_NONE) break
            sleep(4000)
            if (keepAliveDisplayId.get() == DISPLAY_NONE) break
            runCatching { ServiceManager.getPowerManager().userActivity(id) }   // 上报用户活跃
        }
        keepAliveRunning.set(false)
    }.apply { name = "power-user-activity-keepalive"; isDaemon = true }.start()
}

fun destroy() {
    stopUserActivityKeepAlive()
    if (flag) { setDisplayPower(true) }   // 紧急恢复屏幕（shutdown hook/异常清理）
}
```

## 3. ScreenManager：强制显示尺寸

```kotlin
object ScreenManager {
    private val _flag = File("/data/local/tmp/maa_screen_flag")

    fun setForcedDisplaySize(w, h): Boolean {
        flag = true                                       // 落盘标记
        return ServiceManager.getWindowManager().setForcedDisplaySize(DEFAULT_DISPLAY, w, h)
    }
    fun clearForcedDisplaySize(): Boolean { flag = false; ... }
    fun destroy() { if (flag) runCatching { clearForcedDisplaySize() } }   // 紧急恢复
}
```

用途：横屏原生设备虚拟屏 rotation 异常时，强制物理屏上报横屏尺寸（配合 VirtualDisplayManager 的 setForcedDisplaySize）。

## 5. GameAudioMuteController（游戏静音管理）

- 任务开始静音游戏（`AudioManager.adjustStreamVolume(STREAM_MUSIC, 0)` 或按包）
- 任务结束/引擎销毁时 `restoreAll()` 恢复音量——**防游戏永久静音**（force_stop=true 场景尤其重要）。
- `GameMuteCoordinator`（App 侧）在 stopVirtualDisplay 的 finally 里确保 unmute。

## 6. 给复现者的要点清单

1. 触摸：DOWN 前补 ACTION_CANCEL、DOWN 用 WAIT_FOR_FINISH、MOVE/UP 用 ASYNC、synchronized、setDisplayId 到虚拟屏。
2. 触摸回调失败自动注销，防刷屏。
3. 物理屏熄亮用 SurfaceControl（Android10+ 遍历多屏、荣耀特判）。
4. 电源/显示状态**落盘 flag 文件**，异常退出后能紧急恢复（destroy/shutdown hook 检查 flag）。
5. userActivity 保亮虚拟屏（4s 周期）。
6. 游戏音量必须可恢复（restoreAll），force_stop 重启游戏时防止永久静音。
