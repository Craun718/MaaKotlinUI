# 参考项目 深度拆解 15：应用层与周边功能

> 前 14 篇覆盖核心引擎链路，本篇补齐应用层：悬浮窗（overlay）、定时任务（schedule）、
> 更新（update）、权限管理（PermissionManager）、依赖注入（koin）、Shizuku 引导（InstallHelper/Readiness）。

---

## 1. Koin 依赖注入（koin 包）

- **AppModule**：全局单例——AppSettingsManager、RemoteServiceManager、MaaCompositionService、
  MaaResourceLoader、ResourceInitService、MaaSessionLogger、MaaCallbackDispatcher、
  TaskChainStatusTracker、AppWatchdog、GameMuteCoordinator、UnifiedStateDispatcher、
  PermissionManager、各 Repository/DataSource（DataStore、网络、成就）。
- **UseCaseModule**：用例层（更新检查、任务启动等）。
- **ViewModelModule**：Compose ViewModel（BackgroundTaskViewModel 等）。
- **FloatingWindowModule**：悬浮窗相关（OverlayController 等）。

`MaaApplication.onCreate` 里 `startKoin { androidContext(app); modules(...) }`，一切注入统一入口。

---

## 2. 悬浮窗（overlay 包）

- **OverlayController**：悬浮球 + 控制面板宿主，负责悬浮窗生命周期（添加/移除/权限校验）。
- **FloatBall**：悬浮球 UI（可拖动、点击展开面板）。
- **OverlayViewModelOwner**：把 ViewModel 桥接到悬浮窗（悬浮窗是独立 Context/窗口）。
- **border/**：全屏边框指示（任务边界高亮）。
- **screensaver/**：屏保遮罩（后台任务时遮住画面防烧屏/防偷看），ScreenSaverOverlayManager 与 MainActivity keepScreenOn 联动。

悬浮窗典型权限：SYSTEM_ALERT_WINDOW（悬浮窗）——由引擎进程 shell 身份代授（grantFloatingWindowPermission）或引导用户授权。

---

## 3. 定时任务（schedule 包）

- `ScheduleStrategyRepository`：定时策略持久化（DataStore）。
- `ScheduleAlarmManager`：AlarmManager 精确闹钟调度；**每次 App 启动兜底 rescheduleAll**
  （BootReceiver 依赖 ACTION_MY_PACKAGE_REPLACED/BOOT_COMPLETED，国产 ROM 自启动拦截时闹钟会丢，启动兜底可恢复）。
- `LaunchIntentMapper`：外部 Intent（Tasker/MacroDroid 联动）→ 内部启动请求。
- 定时触发 → `TaskExecutionService`（前台服务）→ `MaaCompositionService.start()`。

## 5. 权限管理（manager/PermissionManager）

- 统一管理 App 所需权限（悬浮窗/通知/电池优化/后台不受限/无障碍/存储）。
- **关键**：通过引擎进程 shell 身份代授游戏/自身权限（grantPermissions → PermissionGrantHelper），
  任务启动前 `grantGameBatteryExemption` 给游戏授予省电豁免+后台不受限。

---

## 6. Shizuku 引导（ShizukuInstallHelper / ShizukuReadiness*）

**ShizukuInstallHelper.checkStatus** 分级：

```kotlin
enum class ShizukuStatus {
    READY,           // Shizuku 服务正常运行
    SUI_AVAILABLE,   // Sui（Magisk 模块）提供服务
    APP_NOT_RUNNING, // Shizuku App 已装但服务未启动
    NOT_INSTALLED    // 未安装
}
fun installShizuku(context)   // assets 内置 shizuku.apk → FileProvider → 安装界面
fun openShizuku(context)      // 打开 Shizuku App
```

**ShizukuReadinessGate / ShizukuReadinessDialog**（presentation/components）：
Compose 包装，按状态显示"未安装→引导安装 / 未启动→引导启动 / 未授权→引导授权"，
**未就绪时禁用核心操作**（与火影版开始任务按钮禁用同思路，但更完整）。

---

## 7. 成就系统（data/achievement）

- AchievementRepository：事件上报（APP_LAUNCH、LOG_EXPORTED、LANGUAGE_CHANGED 等）→ 成就解锁 → Snackbar 提示。
- 轻量激励层，非核心。

---

## 8. i18n / 主题 / CrashHandler / 更新公告

- **i18n**：LocaleBootstrap（启动应用持久化语言）+ UiText/ResourceText（可序列化文案）+ 资源多语言。
- **主题**：SYSTEM/WHITE/DARK/PURE_DARK + 莫奈动态取色（useSystemMonetColor）。
- **CrashHandler**：未捕获异常记录到日志文件（配合导出）。
- **更新公告**：pendingChangelogVersion/Content，新版本展示公告。

---

## 9. 给复现者的要点清单（应用层）

1. Koin 统一 DI，模块化（app/useCase/viewModel/floatingWindow）。
2. 悬浮窗：OverlayController 管理生命周期，可代授 SYSTEM_ALERT_WINDOW。
3. 定时任务：AlarmManager + **启动兜底 rescheduleAll**（防国产 ROM 丢闹钟）。
4. 更新：多更新源 + 自动检查/下载 + FileProvider 安装。
5. 权限：引擎代授（省电/后台不受限）是"游戏不被后台杀"的关键。
6. Shizuku 引导分级（READY/SUI/APP_NOT_RUNNING/NOT_INSTALLED），assets 内置 shizuku.apk 一键安装。
