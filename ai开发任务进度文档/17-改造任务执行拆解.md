## 任务 P0-4：游戏电池豁免 + 后台不受限授予（优先级最高）

**问题**：vivo/澎湃把虚拟屏上的游戏冻结/杀死 → "游戏启动几秒就停止、虚拟屏黑屏"。
**目标**：任务启动前，以引擎 shell 身份给游戏授予"忽略电池优化 + 后台不受限"。

### 涉及文件
- `app/src/main/aidl/com/maafw/naruto/IRemoteEngineService.aidl`（加方法）
- `app/src/main/java/com/maafw/naruto/remote/RemoteEngineServiceImpl.kt`（实现）
- `app/src/main/java/com/maafw/naruto/MainActivity.kt`（调用）

### AIDL 增加

```aidl
/** 为指定包授予权限位：1=省电豁免 2=后台不受限 4=通知 8=悬浮窗 16=存储 32=无障碍 */
int grantPermissions(String packageName, int permissions);
```

### 引擎侧实现（RemoteEngineServiceImpl）

```kotlin
override fun grantPermissions(packageName: String?, permissions: Int): Int {
    if (packageName.isNullOrBlank()) return 0
    var granted = 0
    // 1) 忽略电池优化（省电豁免）——shell 可直接调 PowerManager 隐藏 API
    if (permissions and 1 != 0) {
        runCatching {
            val pm = context.getSystemService(Context.POWER_SERVICE) as PowerManager
            val m = pm.javaClass.getMethod(
                "setPowerSaveWhitelistApp", String::class.java, Boolean::class.java
            ) // @hide
            m.isAccessible = true
            m.invoke(pm, packageName, true)
            granted = granted or 1
        }.onFailure { Ln.w("grantPermissions: 省电豁免失败 ${it.message}") }
    }
    // 2) 后台不受限（AppOps 允许后台运行）——shell 可改 AppOps
    if (permissions and 2 != 0) {
        runCatching {
            val appOps = context.getSystemService(Context.APP_OPS_SERVICE) as android.app.AppOpsManager
            val uid = context.packageManager.getApplicationInfo(packageName, 0).uid
            // OP_RUN_IN_BACKGROUND = 63, OP_RUN_ANY_IN_BACKGROUND = 64
            val mode = android.app.AppOpsManager.MODE_ALLOWED
            val setMode = appOps.javaClass.getMethod(
                "setMode", Int::class.javaPrimitiveType, Int::class.javaPrimitiveType,
                String::class.java, Int::class.javaPrimitiveType
            )
            setMode.isAccessible = true
            setMode.invoke(appOps, 63, uid, packageName, mode)
            setMode.invoke(appOps, 64, uid, packageName, mode)
            granted = granted or 2
        }.onFailure { Ln.w("grantPermissions: 后台不受限失败 ${it.message}") }
    }
    return granted
}
```

## 任务 P0-3：虚拟屏补齐 Android13+ 防冻结 flags

**问题**：虚拟屏被系统当"未信任/未解锁/非焦点屏"冻结 → 黑屏。

### 涉及文件
- `app/src/main/java/com/maafw/naruto/remote/internal/VirtualDisplayManager.kt`

### 实现（对照 Meow buildDisplayFlags）

```kotlin
private fun buildDisplayFlags(): Int {
    var flags = (DisplayManager.VIRTUAL_DISPLAY_FLAG_PUBLIC
        or DisplayManager.VIRTUAL_DISPLAY_FLAG_PRESENTATION
        or DisplayManager.VIRTUAL_DISPLAY_FLAG_OWN_CONTENT_ONLY
        or VIRTUAL_DISPLAY_FLAG_SUPPORTS_TOUCH
        or VIRTUAL_DISPLAY_FLAG_DESTROY_CONTENT_ON_REMOVAL)   // 已有 0x3dcb 部分

    if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.TIRAMISU) {   // API 33
        flags = flags or VIRTUAL_DISPLAY_FLAG_TRUSTED
            or VIRTUAL_DISPLAY_FLAG_OWN_DISPLAY_GROUP
            or VIRTUAL_DISPLAY_FLAG_ALWAYS_UNLOCKED
            or VIRTUAL_DISPLAY_FLAG_TOUCH_FEEDBACK_DISABLED
        if (Build.VERSION.SDK_INT >= Build.VERSION_CODES.UPSIDE_DOWN_CAKE) {   // API 34
            flags = flags or VIRTUAL_DISPLAY_FLAG_OWN_FOCUS
                or VIRTUAL_DISPLAY_FLAG_DEVICE_DISPLAY_GROUP
                or VIRTUAL_DISPLAY_FLAG_STEAL_TOP_FOCUS_DISABLED
        }
    }
    return flags
}
```

> 若火影 VirtualDisplayManager 已有本地常量，直接补：
> `TRUSTED=1 shl 10, OWN_DISPLAY_GROUP=1 shl 11, ALWAYS_UNLOCKED=1 shl 12, TOUCH_FEEDBACK_DISABLED=1 shl 13, OWN_FOCUS=1 shl 14, DEVICE_DISPLAY_GROUP=1 shl 15, STEAL_TOP_FOCUS_DISABLED=1 shl 16`。

### 验证
- Android13+ 设备后台模式跑任务，长时间息屏后预览/截图仍正常（不黑屏）。

override fun heartbeat(pid: Int) {
    appPid.set(pid)

}

// init 里启动看门狗
private fun startHeartbeatWatchdog() {
    Thread {
        while (!destroyed) {
            try { Thread.sleep(5_000) } catch (_: InterruptedException) { return@Thread }
            val pid = appPid.get()
            if (pid <= 0) continue
            if (!java.io.File("/proc/$pid").exists()) {
                Ln.w("$TAG App(pid=$pid) 已死亡，引擎自杀")
                destroy()
                return@Thread
            }
        }
    }.apply { name = "engine-heartbeat-watchdog"; isDaemon = true }.start()
}

## 任务 P0-2：shutdown hook 紧急清理

**问题**：引擎被强杀时游戏静音/虚拟屏残留。

### 涉及文件
- `RemoteEngineServiceImpl.kt`

### 实现

```kotlin
init {
    Runtime.getRuntime().addShutdownHook(Thread {
        runCatching { performEmergencyCleanup() }
    }.apply { name = "remote-shutdown-hook" })
}

/** 任何退出路径统一清理：恢复静音/虚拟屏/唤醒锁/引擎 */
private fun performEmergencyCleanup() {
    runCatching { setAudioMutedInternal(false) }      // 恢复游戏声音
    runCatching { VirtualDisplayManager.stop() }       // 释放虚拟屏
    runCatching { releaseEngineWakeLock() }            // 释放唤醒锁
    runCatching { engine?.let { runBlocking { it.destroy() } } }   // 销毁 MaaFramework
}
```
（把 destroy() 里的清理逻辑抽到 performEmergencyCleanup，destroy/看门狗/hook 共用。）

### 验证
- 任务中 kill -9 引擎进程（通过 shell），游戏声音未被永久静音、无残留虚拟屏。

### 引擎侧已有（若没有则加）

### AppWatchdog（App 侧，每 5s）

```kotlin
class AppWatchdog(private val remote: IRemoteEngineService, private val pkg: String) {
    companion object {
        private const val POLL_MS = 5_000L
        private const val REPIN_GRACE_MS = 5_000L
        private const val MAX_REPIN = 3
    }
    private var job: Job? = null
    private var driftFirstSeen = 0L
    private var repinAttempts = 0

    fun start(scope: CoroutineScope) {
        job = scope.launch {
            while (isActive) {
                delay(POLL_MS)
                val alive = runCatching { remote.isAppAlive(pkg) }.getOrDefault(2)
                if (alive == 1) { Log.w(TAG, "游戏进程已死亡"); onGameDied(); break }
                if (alive != 0) continue
                // 漂移检测
                val onDisplay = runCatching { remote.isAppOnVirtualDisplay(pkg) }.getOrDefault(true)
                if (!onDisplay) tryRepin() else { driftFirstSeen = 0; repinAttempts = 0 }
            }
        }
    }
    private suspend fun tryRepin() {
        if (repinAttempts >= MAX_REPIN) return
        val now = SystemClock.elapsedRealtime()
        if (driftFirstSeen == 0L) { driftFirstSeen = now; return }
        if (now - driftFirstSeen < REPIN_GRACE_MS) return
        val ok = runCatching { remote.moveAppToVirtualDisplay(pkg) }.getOrDefault(false)
        if (ok) { driftFirstSeen = 0; repinAttempts = 0 } else repinAttempts++
    }
    fun stop() { job?.cancel(); job = null }
}
```

### 验证
- 后台任务中 `am start` 把游戏挪到主屏 → 5s 宽限期后自动拉回虚拟屏。

## 任务 P0-6：服务状态机 + 自动重连

**问题**：绑定失败/binder 死亡后无自动恢复。

### 涉及文件
- `MainActivity.kt`（把 remoteBound 布尔升级为状态）

### 实现要点（在现有绑定基础上增量改）

```kotlin
private sealed class EngState {
    object Disconnected : EngState()
    object Connecting : EngState()
    object Died : EngState()
    data class Connected(val svc: IRemoteEngineService) : EngState()
    data class Error(val e: Throwable) : EngState()
}
@Volatile private var engState: EngState = EngState.Disconnected

// 绑定成功：EngState.Connected；binder 死亡（linkToDeath）：Died → 自动重绑 1 次
// onServiceDisconnected：若曾 Connected → Died → 自动 bindRemoteEngine()
// 绑定失败：Error → 5s 后自动重试（最多 2 次）
```

**关键增量**：
1. 在 `newServiceConnection().onServiceConnected` 里对 binder `linkToDeath`（App 侧感知引擎死亡）。
2. `onServiceDisconnected` 若 `wasConnected` → 置 Died → 自动 `bindRemoteEngine()`。
3. 绑定失败（tryBindShizukuService 返回 false 且 3 方案均败）→ `delayed(5s) { bindRemoteEngine() }`（重试上限 2）。

### 验证
- 任务中杀引擎进程 → App 5s 内自动重连并恢复"已连接"。

### 实现

```kotlin
class LogcatCaptureServiceImpl : ILogcatService.Stub() {
    private val targets = ConcurrentHashMap<Int, Process>()
    init { /* 看门狗：pid 消失则停 logcat */ }
    override fun startCapture(appPid: Int, servicePid: Int, userDir: String) {
        val dir = File(userDir, "debug/logcat").apply { mkdirs() }
        listOf(servicePid to "core", appPid to "app").forEach { (pid, tag) ->
            if (!targets.containsKey(pid)) {
                val out = File(File(dir, tag), "logcat_${ts()}.log")
                targets[pid] = ProcessBuilder("logcat", "-T", "10", "--pid=$pid")
                    .redirectErrorStream(true).start().also { p ->
                        Thread { p.inputStream.use { i -> out.outputStream().use { i.copyTo(it) } } }.start()
                    }
            }
        }
    }
}
```
绑定方式复用主引擎绑定（随机 tag + version 递增，processNameSuffix("logcat")）。

### 验证
- debugMode 下任务运行，`{userDir}/debug/logcat/core/*.log` 持续增长含引擎日志。
